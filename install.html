🧩 Tampermonkey Script Installer

ServiceNow and Netskope automation suite for Deloitte teams

Requires the Tampermonkey browser extension
How to install a script: Click Install on any card below. A new tab will open with the raw script file. Tampermonkey detects it automatically and shows an installation dialog — review the permissions and click Install in that dialog. Once installed, scripts update themselves automatically whenever a new version is published to this repo. If the install dialog does not appear, open Tampermonkey and use Utilities > Install from URL.

Installing script

A new tab is about to open with the raw script file. Tampermonkey will detect it and show an installation prompt.

1. Click Open below to open the script in a new tab.
2. Tampermonkey shows an installation dialog in that tab.
3. Review the permissions, then click Install in that dialog.
4. Close the tab and return here to install the next script.
